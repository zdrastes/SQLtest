# Changelog

## 3.0.0 — 2026-11-23

### Добавлено
- **Автопроверка SQL-запросов** (`sql-checker.js`): движок SQLite в браузере
  (sql.js 1.13 через CDN), каждая проверка выполняется на свежей копии базы.
  SELECT-задания сравниваются с эталоном как мультимножество строк (порядок
  строк и имена столбцов не важны, допуск 0.01 для чисел); DML и транзакции —
  по итоговому состоянию таблиц. Грациозный офлайн-фолбэк с понятным сообщением.
- **10 заданий в каждом варианте** (было 7) с уровнями сложности ⭐/⭐⭐/⭐⭐⭐:
  оконные функции `RANK()`/`ROW_NUMBER()`, коррелированные подзапросы,
  `NOT EXISTS`, self-join, `CASE`, `COALESCE`, `HAVING`, `strftime`,
  DML с подзапросами и транзакции.
- **Обогащённые схемы и данные** (в 2–3 раза больше строк): цены и даты
  поступления у товаров, `hire_date` у сотрудников, таблица `order_items` и
  иерархия категорий (`parent_category_id`) в интернет-магазине.
- **Подсказки** к каждому заданию и **шкала прогресса** (N из 10) с сохранением
  в localStorage и кнопкой сброса.
- **Кнопка «Показать решение»** — эталонные решения вынесены в `solutions.js`
  (lazy-load) и доступны только после авторизации.
- **expected.js** — сгенерированные эталонные результаты проверок
  (генератор `tools/generate-expected.js`).
- **Тесты** (`tools/test-checker.js`): чистые функции сравнения, прохождение
  эталонными решениями собственной проверки на том же движке, негативные и
  альтернативные сценарии.
- **CHANGELOG.md**.

### Изменено
- **auth.js v3**: пароли хешируются SHA-256 с индивидуальной солью
  (Web Crypto + JS-фолбэк), блокировка входа на 5 минут после 5 неудачных
  попыток с обратным отсчётом на странице входа, синхронизация вкладок через
  BroadcastChannel и событие `storage`.
- **Все 4 варианта переведены на общий `table-manager.js`** — из variant2–4
  убраны дублировавшие его инлайновые копии (около 300 строк CSS на страницу).
- Задания строятся из конфигурации страницы (`window.SQL_TASKS`) единым
  модулем — у всех вариантов одинаковый и расширяемый интерфейс.
- README актуализирован: новая структура, генерация эталонов, честное
  описание ограничений клиентской защиты.

### Удалено
- Пароли в открытом виде и ответы на задания из исходников страниц
  (`variant1–4.html`) и `auth.js`.
- Описание несуществующего `users.json` из README.

### Безопасность
- Пароли: SHA-256(соль:пароль) вместо открытого хранения.
- Блокировка перебора паролей (5 попыток → 5 минут).
- Сравнение хешей за константное время.
- Документированное ограничение: статический сайт не защищает клиентские
  файлы от просмотра; для реальной защиты нужен бэкенд.

# SQL Database Explorer

Интерактивное веб-приложение для изучения SQL: 4 варианта по 10 практических заданий
трёх уровней сложности с автоматической проверкой запросов прямо в браузере.

## 📋 Описание проекта

SQL Database Explorer — образовательная платформа, которая предоставляет:

- **4 варианта заданий** по SQL: товары и склады, сотрудники и проекты, университет, интернет-магазин
- **Автопроверку запросов**: SQLite (sql.js) выполняет запрос студента на свежей копии базы и сравнивает результат с эталоном — без сервера
- **10 заданий в каждом варианте** трёх уровней сложности: ⭐ базовый, ⭐⭐ средний, ⭐⭐⭐ продвинутый
- **Интерактивные схемы баз данных** и просмотр содержимого всех таблиц
- **Шкала прогресса** с сохранением в localStorage
- **Подсказки и эталонные решения** — только для администратора после авторизации

## 🎯 Задания

В каждом варианте 10 заданий: от сортировок и группировок до оконных функций
(`RANK()`, `ROW_NUMBER()`), коррелированных подзапросов, `NOT EXISTS`, self-join,
`CASE`, `HAVING`, DML-операций и транзакций. Запросы студентов проверяются
автоматически: для SELECT сравнивается результирующий набор строк, для
UPDATE/DELETE и транзакций — итоговое состояние таблиц.

## 🚀 Возможности

### Для студентов
- **Автопроверка без регистрации**: кнопка «Проверить» у каждого задания
- **Прогресс**: сколько заданий решено, сохраняется между визитами
- **Порядок строк и имена столбцов не важны**: проверяется состав и значения результата

### Для преподавателей (после авторизации)
- **Подсказки**: наводящие тексты, не раскрывающие решение
- **Эталонные решения**: кнопка «Показать решение»
- **Пароли хешируются** (SHA-256 с индивидуальной солью, Web Crypto)
- **Защита от перебора**: после 5 неудачных попыток вход блокируется на 5 минут
- **4 разных набора данных** для распределения между студентами

## 📦 Установка и запуск

1. **Клонирование репозитория**
   ```bash
   git clone <repository-url>
   cd SQLtest
   ```

2. **Запуск проекта**
   - Откройте `index.html` в браузере, или
   - поднимите локальный сервер:
     ```bash
     python -m http.server 8000
     # или
     npx http-server
     ```
   Проект также размещается на GitHub Pages без дополнительной сборки.

3. **Использование**
   - Выберите вариант задания на главной странице
   - Изучите схему базы данных и данные таблиц
   - Пишите SQL-запросы и нажимайте «Проверить»
   - Застряли — преподаватель откроет «Подсказку» (она доступна после авторизации)

> Для работы автопроверки нужен интернет: движок sql.js загружается с CDN.
> Без сети страница продолжает работать, но кнопка «Проверить» сообщит
> о недоступности проверки.

## 🔍 Как работает автопроверка

- В браузер загружается SQLite (sql.js с cdnjs) и на **свежей копии** учебной базы
  выполняется запрос студента — данные на странице никогда не «портятся».
- **SELECT-задания**: результат сравнивается с эталоном как мультимножество строк.
  Порядок строк и имена столбцов не важны; для чисел допускается погрешность 0.01.
- **DML и транзакции**: после выполнения скрипта студента сравнивается итоговое
  состояние указанных в задании таблиц с эталонным.
- Эталонные результаты хранятся в `expected.js`, эталонные тексты решений — в
  `solutions.js` (загружается только по запросу).

## 👤 Настройка пользователей

Учётные записи преподавателей хранятся в `auth.js` в виде `username`, случайной
соли и хеша `SHA-256(соль:пароль)`. Демонстрационные учётки: `AnnaM` и `AntonT`
(пароли выдаёт преподаватель; по умолчанию — `AnnaM123` и `AntonT123`, смените их
перед использованием).

Чтобы добавить или сменить пользователя, выполните в консоли браузера на любой
странице проекта (F12):

```js
const username = 'NEW_USER';
const password = 'НОВЫЙ_ПАРОЛЬ';           // не менее 6 символов, без &<>'"
const salt = [...crypto.getRandomValues(new Uint8Array(16))]
    .map(b => b.toString(16).padStart(2, '0')).join('');
const hash = [...new Uint8Array(await crypto.subtle.digest('SHA-256',
    new TextEncoder().encode(salt + ':' + password)))]
    .map(b => b.toString(16).padStart(2, '0')).join('');
console.log(JSON.stringify({ username, salt, hash, fullName: 'Имя', role: 'admin' }, null, 2));
```

Скопируйте полученный объект в массив `this.users` в `auth.js`.

## 🛠️ Инструменты разработки

После изменения схем, данных или эталонных решений в страницах вариантов
перегенерируйте эталоны и прогоните тесты:

```bash
cd tools
npm install
node generate-expected.js   # пересобрать expected.js
node test-checker.js        # тесты: сравнение, эталоны, негативные сценарии
```

`test-checker.js` проверяет, что каждое эталонное решение проходит собственную
проверку на том же движке (sql.js), что используется в браузере, и что неверные
запросы не засчитываются.

## 🔒 Безопасность (честно)

- Пароли не хранятся в открытом виде: только соль и SHA-256-хеш; вход
  блокируется после 5 неудачных попыток на 5 минут.
- Статический сайт не может защитить клиентские файлы от технически
  подкованного студента: `solutions.js` скачивается по запросу и может быть
  найден в инструментах разработчика, а тексты подсказок лежат прямо в коде
  страниц вариантов. Автопроверка убирает саму необходимость
  смотреть решения, а для по-настоящему скрытых эталонов нужен серверный бэкенд.
- Санитизация пользовательского ввода и экранирование HTML выполняются при
  выводе данных.

Вариант 2 - База данных сотрудников и проектов

Схема базы данных

employees

Таблица сотрудников

idINT PRIMARY KEY
full_nameVARCHAR(100)
department_idINT
positionVARCHAR(100)
salaryDECIMAL(10,2)
hire_dateDATE

projects

Таблица проектов

idINT PRIMARY KEY
nameVARCHAR(100)
clientVARCHAR(100)
budgetDECIMAL(12,2)
statusVARCHAR(20)

employee_projects

Таблица назначений сотрудников на проекты

employee_idINT
project_idINT
roleVARCHAR(50)
hours_workedINT

departments

Таблица отделов

idINT PRIMARY KEY
nameVARCHAR(100)
manager_idINT

Таблицы связаны между собой через ключи: employees.id → employee_projects.employee_id, projects.id → employee_projects.project_id, departments.id → employees.department_id, departments.manager_id → employees.id

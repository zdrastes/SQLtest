Вариант 4 - База данных интернет-магазина

Схема базы данных

customers

Таблица клиентов

idINT PRIMARY KEY
full_nameVARCHAR(100)
emailVARCHAR(100)
phoneVARCHAR(20)
registration_dateDATE

orders

Таблица заказов

idINT PRIMARY KEY
customer_idINT
order_dateDATE
total_amountDECIMAL(10,2)
statusVARCHAR(20)

order_items

Состав заказов (позиции)

order_idINT
product_idINT
quantityINT
priceDECIMAL(10,2)

products

Таблица товаров

idINT PRIMARY KEY
product_nameVARCHAR(100)
category_idINT
priceDECIMAL(10,2)
stock_quantityINT

categories

Таблица категорий (иерархия)

idINT PRIMARY KEY
category_nameVARCHAR(100)
parent_category_idINT

Таблицы связаны между собой через ключи: customers.id → orders.customer_id, orders.id → order_items.order_id, products.id → order_items.product_id, categories.id → products.category_id, categories.parent_category_id → categories.id
